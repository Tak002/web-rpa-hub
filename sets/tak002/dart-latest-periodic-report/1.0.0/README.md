# DART 회사별 최신 정기보고서 PDF 받기

`tak002/dart-latest-periodic-report` · 버전 1.0.0 · web-rpa `>=0.2.0 <0.3.0` · 라이선스 CC0-1.0

## 무엇을 하나

엑셀에 적은 회사명마다 DART(금융감독원 전자공시시스템) 공시검색 화면에서 아래 순서로 작업한다.

1. 공시검색 화면을 열고 1초 기다린 뒤 회사명을 입력한다.
2. 검색창에서 `End` 키를 누르고, 자동완성 목록에서 회사명과 같은 항목을 누른다.
3. 결과를 100건씩 보이게 바꾸고 [검색]을 누른다.
4. 결과 목록에서 처음 나오는 정기보고서(사업보고서·반기보고서·분기보고서)의 보고서명과 접수일을 읽는다.
5. 그 보고서를 열어 첫 화면을 캡처(PNG)하고, [다운로드] 창에서 보고서 PDF를 받은 뒤 창을 닫는다.

로그인은 필요 없다. 접속하는 사이트는 `https://dart.fss.or.kr` 하나다.

## 준비물

- web-rpa 0.2.0 이상 (Edge 또는 Chrome)
- `회사명` 열이 있는 엑셀(xlsx 또는 csv). 세트에 예시 파일 `input/sample.csv`(삼성전자, 현대자동차, SK하이닉스)가 들어 있다.

## 엑셀 열

| 열 | 필수 | 예 | 설명 |
|---|---|---|---|
| 회사명 | 예 | 삼성전자 | DART에 등록된 회사명. 검색창 자동완성 목록에 뜨는 이름과 글자가 같아야 한다 |

## 결과

| 종류 | 이름 | 예 |
|---|---|---|
| 값 | `보고서명` | `반기보고서 (2026.06)` |
| 값 | `접수일` | `2026.08.14` |
| 파일 | `{{회사명}}_최신정기보고서.png` | 보고서 첫 화면 캡처 |
| 파일 | 사이트가 붙인 PDF 이름 | `[삼성전자]반기보고서(2026.08.14).pdf` |

2026-10-20에 예시 3행을 돌려 3행 모두 성공했다. 최신 보고서는 시기마다 바뀌므로 `expected.json`은 정확한 값 대신 모양(보고서명에 사업·반기·분기보고서가 들어 있는지, 접수일이 `YYYY.MM.DD`인지)과 파일이 생겼는지를 확인한다.

## 주의

- **자동완성 때문에 넣은 스텝**: 페이지를 연 뒤 1초 대기와 회사명 입력 뒤의 `End` 키는 DART 검색창의 자동완성 목록이 늦게 뜨거나 입력이 덜 반영되는 것을 막으려고 넣었다. 지우면 자동완성 항목을 못 찾아 실패할 수 있다.
- **이름이 비슷한 회사**: 자동완성 목록에서 회사명과 같은 글자의 항목을 찾는다. 같은 항목이 없거나 여러 개면 그 행은 실패할 수 있으니, 결과의 보고서명과 PDF 이름으로 원하는 회사가 맞는지 확인한다.
- **속도**: 행 사이 최소 3초(`pacing.minRowIntervalMs: 3000`), 한 번에 최대 50행(`pacing.maxRowsPerRun: 50`)으로 선언했다. 공공 사이트에 부담을 주지 않도록 이 값을 줄이지 않는다.
- **공식 API**: 여러 회사의 공시 목록이나 원문을 정기적으로 많이 받아야 한다면 이 세트 대신 금융감독원 OpenDART API(<https://opendart.fss.or.kr/>, 무료 인증키, 하루 이용 한도 있음)를 쓴다.
- **robots.txt**: `https://dart.fss.or.kr/robots.txt`는 검색 로봇에게 보고서 화면(`/dsaf001/main.do`)과 PDF 다운로드(`/pdf/download/`) 경로를 막아 두었다(2026-10-20 확인). 이 세트는 사람이 고른 회사 몇 곳의 보고서를 사람이 하던 순서대로 받는 용도로만 쓰고, 대량 수집에는 쓰지 않는다.
- **이용약관**: DART 이용약관의 자동 접속 관련 문구는 이 세트를 만들 때 따로 확인하지 못했다. 업무에 쓰기 전에 직접 확인한다. 사이트의 이용약관과 자동 접속 정책을 지키는 것은 사용자의 책임이다.
- **녹화 흔적**: 다운로드 스텝(`s8`)의 첫 번째 후보 선택자에 녹화할 때 받은 파일 이름(`[삼성전자]반기보고서(2026.08.14).pdf`)이 남아 있다. 공개된 공시 이름이라 개인정보는 아니다. 다른 회사나 다른 보고서에서는 이 후보가 맞지 않아 다음 후보(다운로드 창 표의 첫 행)로 넘어가 동작한다.
