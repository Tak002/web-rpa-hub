# 서울외국환중개 통화별 직전 월 월말 환율

`tak002/smbs-month-end-fx` · 버전 1.0.0 · web-rpa `>=0.2.0 <0.3.0` · 라이선스 CC0-1.0

## 무엇을 하나

엑셀에 적은 통화 코드마다 서울외국환중개(`http://www.smbs.biz`)의 "월말 매매기준율" 화면에서 아래 순서로 작업한다.

1. 통화를 고르고, 조회 시작 월을 1월로 바꿔 조회한다. 올해 1월부터의 월말 매매기준율 표가 나온다.
2. 사이트가 그 통화를 "고시하지 않습니다"라고 안내하면(예: CNY) 안내 문구를 `비고`에 남기고 화면을 PNG로 캡처한다.
3. 그렇지 않으면 올해 표에서 직전 월 행의 월과 매매기준율, 표의 마지막 행(가장 최근 월)의 월과 매매기준율을 읽고 조회 화면을 PDF로 저장한다.

로그인은 필요 없다. 접속하는 사이트는 `http://www.smbs.biz` 하나다.

## 준비물

- web-rpa 0.2.0 이상 (Edge 또는 Chrome)
- `통화` 열이 있는 엑셀(xlsx 또는 csv). 세트에 예시 파일 `input/sample.csv`(USD, JPY, EUR, CNY, GBP)가 들어 있다.

## 엑셀 열

| 열 | 필수 | 예 | 설명 |
|---|---|---|---|
| 통화 | 예 | USD | 통화 코드 3글자(USD, JPY, EUR 등). 사이트의 통화 목록에 있는 통화만 된다 |

## 결과

| 종류 | 이름 | 예 |
|---|---|---|
| 값 | `직전월` | `2026.09` |
| 값 | `직전월_매매기준율` | `1,358.40` |
| 값 | `최신_월` | `2026.09` |
| 값 | `최신_매매기준율` | `1,358.40` |
| 값 | `비고` | 고시하지 않는 통화만. 예: `CNY는 2016년 1월 1일부터 고시하지 않습니다. …` |
| 파일 | `{{통화}}_월말환율_YYYYMMDD.pdf` | 조회 화면 PDF (실행한 날짜가 붙는다) |
| 파일 | `{{통화}}_고시없음.png` | 고시하지 않는 통화의 안내 화면 |

2026-10-20에 예시 5행을 돌려 5행 모두 성공했다(CNY는 고시없음 분기로 성공). 환율은 달마다 바뀌므로 `expected.json`은 정확한 값 대신 모양(`YYYY.MM`, `1,234.56`)과 파일이 생겼는지를 확인한다. CNY 행은 `replaceValues`로 `비고`만 확인하고, 다른 통화의 값·PDF는 요구하지 않는다.

## 동작 방식

- **직전 월 행 고르기**: 이 사이트는 표의 날짜 칸 글자가 나뉘어 있어 `2026.09` 같은 글자 그대로는 행을 찾을 수 없다. 그래서 조회 시작 월을 1월(`01`)로 두고, 올해(`{{sys:year}}.`가 들어 있는) 행 가운데 `{{sys:month:-1}}`번째 행을 직전 월로 읽는다. 10월에 실행하면 9번째 행, 곧 9월이다.
- **CNY 분기**: 사이트가 "고시하지 않습니다"라고 안내하는 통화는 `고시없음` 블록으로 가고, 나머지는 `값읽기` 블록으로 간다. 두 경우 모두 그 행은 성공으로 기록된다.

## 주의

- **1월에는 실패한다**: 1월에 실행하면 직전 월은 작년 12월인데, 이 버전은 올해 행 가운데서 12번째 행을 찾는다. 1월에는 올해 행이 아직 없으므로 15초 기다린 뒤 그 행이 실패로 기록된다. 연도까지 작년으로 바꾸는 처리는 이 버전에 없다. 1월에는 사이트에서 직접 확인하거나, 레시피의 조회 시작 연도와 행 조건의 `{{sys:year}}`를 작년 값으로 고쳐서 쓴다.
- **월초**: 직전 월 월말 값이 사이트 표에 아직 없으면(월이 바뀐 직후 등) 같은 이유로 행을 찾지 못할 수 있다.
- **평문 http**: `www.smbs.biz`는 암호화하지 않은 `http://`로 접속한다(위험 표시 `insecure-http`). 공개된 환율만 조회하고 아무것도 제출하지 않지만, 회사 보안 정책이 http 접속을 막는다면 쓸 수 없다.
- **속도**: 행 사이 최소 3초(`pacing.minRowIntervalMs: 3000`), 한 번에 최대 50행(`pacing.maxRowsPerRun: 50`)으로 선언했다. 이 값을 줄이지 않는다.
- **공식 API**: 서울외국환중개가 이 화면의 공개 API를 안내하는지는 이 세트를 만들 때 확인하지 못했다. 환율을 정기적으로 많이 받아야 한다면 한국은행 경제통계시스템(ECOS) Open API의 환율 통계를 검토하되, 매매기준율과 기준이 같은지 확인하고 쓴다.
- **robots.txt·이용약관**: `www.smbs.biz`는 robots.txt를 두지 않았다(2026-10-20 확인, 오류 화면이 나온다). 이용약관의 자동 접속 관련 문구는 따로 확인하지 못했다. 사이트의 이용약관과 자동 접속 정책을 지키는 것은 사용자의 책임이다.
- **PDF**: web-rpa를 화면 표시 모드로 실행하면 PDF는 화면 캡처를 A4로 나눈 이미지 PDF라 글자를 선택할 수 없다(web-rpa의 알려진 제한).

## 바뀐 점

- 1.0.0 (2026-10-20): 처음 올림. web-rpa 시연 레시피에서 녹화값(`미국 달러 (USD)`), 녹화 시각·화면 좌표를 지워 만들었다. 조회 시작 월 `01`은 동작에 필요한 값이라 남겼다.
